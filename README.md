# Сайт-визитка: онлайн-группа по шахматам

Одностраничный сайт тренера **Рудякова Павла Павловича** (шахматный клуб «Гамбит», Киев)
для набора детей в онлайн-группу.

## Что внутри

```
index.html    — вся разметка страницы (тексты в двух языках: RU / UA)
styles.css    — оформление и анимации
script.js     — переключение языка, анимации при прокрутке, 3D-конь, параллакс
assets/       — фотографии, скриншоты платформы, логотип клуба
```

Никакой сборки не нужно: это обычные HTML/CSS/JS-файлы.
Чтобы посмотреть сайт локально — откройте `index.html` в браузере.

## Что нужно заменить перед публикацией

1. **Контакты.** В `index.html` найдите комментарий
   `<!-- ЗАМЕНИТЕ КОНТАКТЫ НА СВОИ ... -->` (секция «Следующая группа уже набирается»)
   и подставьте свой ник в Telegram, номер Viber и телефон:

   ```html
   <a class="btn btn-gold" href="https://t.me/USERNAME">Telegram</a>
   <a class="btn btn-ghost" href="viber://chat?number=%2B380000000000">Viber</a>
   <a class="btn btn-ghost" href="tel:+380000000000">+380 00 000 00 00</a>
   ```

2. **Тексты, которые стоит проверить под себя** (я написал их «по умолчанию»):
   структура занятия в секции «Как проходит занятие» (10 / 20 / 20 / 10 минут),
   список того, что входит в стоимость, и ответы в блоке «Вопросы» —
   особенно про возраст (5–6 лет) и пропущенные занятия.

3. **Цена и расписание.** Цена стоит в двух местах: блок статистики в шапке
   (`data-count="2000"`) и карточка стоимости. Количество занятий — «8 занятий».

## Два языка

Русский текст лежит прямо в HTML, украинский — в атрибуте `data-uk` рядом с ним:

```html
<h3 data-uk="Відеозв'язок">Видеосвязь</h3>
```

Переключатель RU / UA в шапке подменяет тексты и запоминает выбор в браузере.
Чтобы сайт открывался сразу на украинском, поменяйте порядок:
положите украинский текст внутрь тега, а русский — в `data-uk`,
и замените `data-lang` у кнопок.

## Публикация

Самый простой способ — GitHub Pages:

1. Settings → Pages → Source: **Deploy from a branch**;
2. Branch: ветка с этими файлами, папка `/ (root)`;
3. Через минуту сайт будет доступен по адресу
   `https://<логин>.github.io/<репозиторий>/` — эту ссылку можно отправлять родителям.

Так же подойдёт любой хостинг статики (Netlify, Vercel, Cloudflare Pages)
или обычная загрузка папки на хостинг по FTP.

## Фотографии

Фото в `assets/` уже развёрнуты в правильную ориентацию и сжаты в WebP.
Если будете менять — сохраняйте те же имена файлов и примерно те же пропорции:

| Файл | Что это | Пропорции |
|---|---|---|
| `coach.webp` | фото тренера | 1400 × 985 |
| `group.webp` | фото с детьми в клубе | 1600 × 900 |
| `platform-board.webp` | скриншот доски | 1600 × 758 |
| `platform-dashboard.webp` | скриншот кабинета | 1600 × 762 |
| `logo.webp`, `logo.png`, `favicon.png` | логотип клуба | квадрат |
