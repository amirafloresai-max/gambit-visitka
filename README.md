# Сайт-визитка: онлайн-группа по шахматам

Одностраничный сайт тренера **Рудякова Павла Павловича** (шахматный клуб «Гамбит», Киев)
для набора детей в онлайн-группу. Основной язык сайта — **украинский**,
русская версия включается переключателем RU / UA в шапке.

## Что внутри

```
index.html    — вся разметка страницы (украинский текст + русский в data-ru)
styles.css    — оформление и анимации
script.js     — переключение языка, анимации при прокрутке, 3D-конь, параллакс
assets/       — фотографии, скриншоты платформы, логотип клуба
```

Никакой сборки не нужно: это обычные HTML/CSS/JS-файлы.
Чтобы посмотреть сайт локально — откройте `index.html` в браузере.

## Порядок блоков

1. **Первый экран** — фото с детьми в клубе, имя, роль и краткое описание группы;
2. **Тренер** — фото, рассказ о себе, принципы работы и блок «Достижения и опыт»;
3. **Занятия** — как я веду тренировки (6 принципов) и структура часа;
4. **Платформа** — возможности и скриншоты;
5. **Клуб** — логотип, цитата, ссылка на club-gambit.kiev.ua;
6. **Стоимость** → **Вопросы** → **Контакты**.

## Что нужно заменить перед публикацией

1. **Достижения.** В секции «Тренер» четыре карточки с заглушками
   `[звання]` и `[N]` — их нужно заменить на реальные данные
   (звание/разряд, стаж, число учеников, призовые места).
   В HTML блок помечен комментарием `ЗАПОЛНИТЕ СВОИМИ ДАННЫМИ`.
   Не забудьте поправить и русский перевод в атрибуте `data-ru` у подписи.

2. **Контакты.** Найдите комментарий `ЗАМЕНИТЕ КОНТАКТЫ НА СВОИ`
   (секция «Наступна група вже набирається») и подставьте свои:

   ```html
   <a class="btn btn-gold" href="https://t.me/USERNAME">Telegram</a>
   <a class="btn btn-ghost" href="viber://chat?number=%2B380000000000">Viber</a>
   <a class="btn btn-ghost" href="tel:+380000000000">+380 00 000 00 00</a>
   ```

3. **Тексты, которые стоит проверить под себя** (написаны «по умолчанию»):
   структура занятия (10 / 20 / 20 / 10 минут), список того, что входит
   в стоимость, и ответы в блоке «Вопросы» — особенно про возраст (5–6 лет)
   и пропущенные занятия.

4. **Цена и расписание.** Цена стоит в двух местах: блок статистики
   на первом экране (`data-count="2000"`) и карточка стоимости.

## Два языка

Украинский текст лежит прямо в HTML, русский — в атрибуте `data-ru` рядом с ним:

```html
<h3 data-ru="Видеосвязь">Відеозв’язок</h3>
```

Переключатель RU / UA подменяет тексты и запоминает выбор в браузере.
Если меняете текст — правьте обе версии.
Чтобы убрать русский совсем, достаточно удалить блок `<div class="lang">`
в шапке: страница останется украинской, атрибуты `data-ru` ни на что не влияют.

## Публикация

Самый простой способ — GitHub Pages:

1. Settings → Pages → Source: **Deploy from a branch**;
2. Branch: ветка с этими файлами, папка `/ (root)`;
3. Через минуту сайт будет доступен по адресу
   `https://<логин>.github.io/<репозиторий>/` — эту ссылку можно отправлять родителям.

Так же подойдёт любой хостинг статики (Netlify, Vercel, Cloudflare Pages)
или обычная загрузка папки на хостинг по FTP.
